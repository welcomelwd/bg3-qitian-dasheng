// V0.1 Monkey Agility source alignment:
// - vanilla Unarmoured Defence uses ACOverrideFormula(10,true,Dexterity,Wisdom).
// - vanilla conditions require no armour and no shield.
// - PassiveData supports ActionResource(Movement,...), JumpMaxDistanceMultiplier and FallDamageMultiplier.
// - mobility/fall behavior is kept in a hidden helper so the AC condition does not disable it.
// V0.1 Ruyi Mastery source alignment:
// - mature Monk Martial Arts data uses IsDexterityGreaterThanStrength() as the conditional gate.
// - MonkWeaponAttackOverride() changes eligible monk-weapon attacks to Dexterity only when Dexterity is higher.
// - when Strength is equal or higher, the condition is false and the weapon keeps its normal Strength path.
// - V0.1 intentionally avoids forced WeaponAttackRollAbilityOverride(Dexterity) and avoids adding Finesse to every weapon.
// V0.1 Copper Head / Iron Arm source alignment:
// - passive unlocks a Yes/No OnPreDamage Interrupt and spends ReactionActionPoint:1 only when accepted.
// - the interrupt is restricted to Bludgeoning/Piercing/Slashing primary damage types.
// - a temporary BOOST status applies flat 1d8+WisdomModifier reduction only to B/P/S damage.
// - a hidden cleanup passive removes that status on OnDamaged or OnDamagedPrevented so it cannot leak to later hits.
// V0.1 Somersault Cloud source alignment:
// - Cloud Momentum uses IF(IsMeleeAttack()):Advantage(AttackRoll) and a hidden OnAttack cleanup passive.
// - range growth uses cumulative UnlockSpellVariant + ModifyTargetRadius(Multiplicative,...) boosts.
// - planned range curve is 12m at L2, 15m at L5, 18m at L9, and 21m at L12.
// Verified pattern source: vanilla-derived Stats uses UnlockSpell(<spell>,AddChildren,<GUID>)
// to add a child spell to a linked container.
// V0.2 defense source alignment:
// - Monk_7_Evasion and Rogue_7_Evasion inherit the vanilla Evasion passive.
// - public BG3 data uses Resistance(<Physical>, ResistantToNonMagical).
// - public BG3 item data uses Advantage(SavingThrow, Constitution).
// V0.3 Three Heads, Six Arms source alignment:
// - public BOOST statuses can attach Passives such as ExtraAttack_2.
// - ExtraAttack_2 is the improved martial extra-attack chain used by level-11 multiattack creatures.
// V0.4 Fa Tian Xiang Di source alignment:
// - vanilla ENLARGE uses ObjectSize(+1) and ScaleMultiplier(1.33).
// - the active form is unlocked by this passive; its cooldown and giant mechanics live in FaTianXiangDi.txt.
// V1.0 Qitian Dasheng capstone source alignment:
// - public BG3 PassiveData uses ActionResource(...) for permanent resource-capacity changes.
// - StatusImmunity(SG_Charmed) and StatusImmunity(SG_Frightened) are public-data-aligned status-group immunities.
// - no extra ActionPoint, BonusActionPoint, ExtraAttack_2 or new active spell is granted by the capstone.
// IMPORTANT: 1f3a673b-dc8b-4eca-9097-c6605a3de947 is a project planning UUID. When Toolkit creates the real
// container UUID, replace this GUID everywhere if Toolkit assigns a different value.
