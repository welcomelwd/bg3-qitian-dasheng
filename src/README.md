# Source data

`src/` contains hand-authored, implementation-oriented data for Qitian Dasheng.

- `src/stats/` contains BG3 Stats drafts.
- `src/toolkit/` is reserved for records exported from or verified in BG3 Toolkit.

A Stats draft is **not** considered runtime-ready until inherited entries, functors, resource identifiers and conditions have been validated against known-good Toolkit/base-game records.
