# 平衡基线

V0.1 目标不是把孙悟空做成“GM 权限”，而是让其强度接近高构筑武僧/战士等原版职业，同时通过仙力形成爆发窗口。

## 初始建议

- 仙力：2 → 3 → 4 → 5 → 6，短休恢复。
- 筋斗云：1 仙力，Bonus Action。
- 定海一棒：2 仙力，Action。
- 火眼金睛：1 仙力，Bonus Action。
- 金箍棒：+2 Legendary，先不做 +3。

## 重点观测

- Bonus Action 经济是否过强。
- 筋斗云 + Advantage 是否导致每回合过于稳定。
- 定海一棒在 5/11 级成长后是否超过同级范围技能。
- 短休恢复是否让多场战斗持续爆发过强。
