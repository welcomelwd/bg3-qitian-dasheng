# 齐天大圣职业设计

## 核心幻想

玩家应经历“石猴 → 美猴王 → 齐天大圣”的成长，并通过高机动棒术、火眼金睛与变化神通形成区别于武僧/战士/德鲁伊的独立玩法。

## 核心属性

- 主属性：Strength
- 神通属性：Wisdom
- 次级构筑：Dexterity
- 生命：Base HP 10，HP/Level 6

## 核心循环

1. 筋斗云接近关键目标。
2. 云势强化下一次近战攻击。
3. 金箍棒常规输出或定海一棒打控制/范围爆发。
4. 火眼金睛处理隐形、幻象和高价值敌人。
5. 用仙力作为节奏阀门，短休恢复。

## 后续子职业

- 斗战胜佛：金箍棒、暴击、正面爆发。
- 七十二变：变化、分身、潜入与战术工具。
- 灵明石猴：感知施法、风雷火与仙术控制。
