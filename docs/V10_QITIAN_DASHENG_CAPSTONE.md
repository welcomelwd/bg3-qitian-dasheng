# V1.0 L12 齐天大圣封顶被动

## 目标

L12 不再追加第四个爆发型主动技能，而是用一个永久被动把整套大圣玩法封顶：更宽裕的仙力池、更高的常驻机动、以及对魅惑与恐惧的彻底免疫。

## 设计

`QTD_Passive_QitianDasheng`

- 等级：12
- 类型：永久 Passive
- 仙力上限：+2
- L12 预期仙力总上限：8
- 移动距离：+3m
- 免疫：`SG_Charmed`
- 免疫：`SG_Frightened`
- 不新增主动技能
- 不提供额外 Action / Bonus Action
- 不提升到 `ExtraAttack_2` 或 `ExtraAttack_3`
- 不刷新法天象地的长休使用标记

## 为什么不是新的大招

L10 的三头六臂已经负责多段近战爆发，L11 的法天象地负责最高阶形态爆发。L12 如果再加入独立大招，会继续抬高动作经济和瞬时爆发，同时挤压已有神通的存在感。

因此 L12 选择强化“整套系统”：

1. 仙力从 6 提升到 8，使玩家在一场高强度战斗中能更自由组合筋斗云、七十二变、分身和高阶神通。
2. 常驻 +3m 移动让终局悟空真正具备压迫性的战场机动，但不会制造额外完整动作。
3. 魅惑与恐惧免疫体现大圣心性已定，不再受寻常精神控制左右。

## Stats 对齐依据

公开 BG3 派生 Stats 数据中存在以下可复用模式：

- `PassiveData` 的 `Boosts` 使用 `ActionResource(...)` 改变永久资源容量。
- `MovementSpeed(...)` 作为常驻移动加成。
- `StatusImmunity(SG_Charmed)` 与 `StatusImmunity(SG_Frightened)` 作为状态组免疫。

本实现不依赖 Script Extender。

## Toolkit 验证门

- L11 升 L12 后仙力最大值从 6 正确变为 8。
- 短休仍然按现有 `QTD_SageQi` 规则恢复，不出现超过 8 或重复叠加。
- 重洗职业、升级/降级不会永久残留额外 2 点仙力。
- +3m Movement 与灵猴身法的 +3m 正确叠加，总移动提升符合预期。
- 魅惑与恐惧类状态确实被状态组免疫覆盖。
- 不产生额外 Action、Bonus Action 或第三/第四级额外攻击链。
